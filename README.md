# flutter_application_2_health_app

Prototipo de alta fidelidade, feito com Flutter, de um aplicativo para contar e catalogar treinos e atividades físicas, desenvovido para a matéria de Interface Humano Computador do curso de Ciências da Computação.
Feito por: Pedro Moreira Guerra de Almeida e Caio Vasconcelos Araújo Figueiredo 


High-fidelity prototype, made with Flutter, of an app to track and catalog workouts and physical activities, developed for the Human-Computer Interaction course in the Computer Science program.
Made by: Pedro Moreira Guerra de Almeida and Caio Vasconcelos Araújo Figueiredo
